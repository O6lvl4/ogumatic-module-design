# 語彙（glossary）

| 日本語 | 英語 | 意味 |
| --- | --- | --- |
| 箱 | box | モジュール。package / crate / ディレクトリの単位 |
| 札 | card | `box.yaml`。箱の正 |
| 地図 | atlas | `ogumatic.yaml`。repo の全札を列挙する 1 枚 |
| 眼 | eye | 六段の機械検査 |
| 語彙 | vocabulary | 値と型。最下段 |
| 計器 | meter | 純ロジック |
| 写し | mirror | 外界 1 つを 1 関数 1 呼び出しで写す葉。副作用はここだけ |
| 翻訳 | translator | 写しの形を語彙の形へ |
| 名簿 | registry | 翻訳を全部知り組み立てる唯一の箱 |
| 顔 | facade | 入口。4 本まで |
| 偽物 | fake | mirror と同じ入口を持つ副作用の無い実装 |
| 契約テスト | contract test | 本物と偽物に同じケースを流すテスト |
| 資料 | catalog | 変わる部分をコードの外に出したデータ |
| 証拠 | evidence | テスト・bench・proofs |
| 見本 | demo | 使い手そのもの |
| 閉じる | close | `state: closed`。以後手で直さず再生成する |
| 育てる | nurture | `state: nurtured`。年単位で境界を確かめる箱。3 つまで |
| 渡す | hand over | 引き上げを依存で行うこと |
| kit | kit | 時計・ID・fs・http・env の写しを集めた言語別の repo |
| 落とす / 告げる | fail / warn | 眼の判定 |
