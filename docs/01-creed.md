# 01 心得（五行）

## 原文

```
外界は写してから触る
表は狭く、中は深く
名詞で切り、矢印は一方向
試験と証拠を隣に置く
数日で書き切り、閉じる
```

## 七五調

```
写してのちに、世に触れよ
口はせまくて、腹ふかく
名で断ち切りて、矢は一路
隣に証、われ黙す
日ならず書きて、蓋を閉づ
```

## 短歌二首

```
写しては　世に触るるもの　口せまく　腹はふかくて　矢は一路なり
名で断ちて　隣に証　われ黙す　日ならず書きて　蓋を閉づべし
```

一首目が箱の形、二首目が箱の作法。

## 意味

| 行 | することがら | 根拠（1.0 の実測） |
| --- | --- | --- |
| 写してのちに、世に触れよ | 外の API に触る前に「1 関数 1 呼び出し」の写しを作り、以後はそれにしか触らない。時計と ID 生成も外界に数える | MOARuntime 30 本（2015）、Runtime.swift 22 本（2018）、syncenv Storage × 4 実装（2025）、gulp-coach の Clock / IdGenerator |
| 口はせまくて、腹ふかく | 公開する入口は 3〜4 本。複雑さは全部その裏に置く | MOAspects 4 本 / 888 行、GADInjector 3 本 / 473 行 |
| 名で断ち切りて、矢は一路 | 箱は業務の名詞で切り、層の名前で切らない。依存は変わりにくい方へ一方向 | archgopher の 31 package が全部名詞、許可表テストで一方向を強制 |
| 隣に証、われ黙す | 箱ごとに同じ大きさのテストを隣に置く。Demo・spec・bench も同居させる。証拠が口の代わりをする | MOARuntime 30 メソッドに 32 テスト、examples 21 repo、spec 13、bench 12 |
| 日ならず書きて、蓋を閉づ | 100〜700 行の箱を 1〜4 日で書き切り、以後は触らない。新しい考えは新しい箱で試す | SwiftyAPIRequest 4 日 31 コミット、runtime-kit 4 日 30 コミット |

## 2.0 で足した一行

```
渡すは依存、写すにあらず
```

引き上げは依存で行い、コピーで行わない。1.0 に唯一無かった作法（Swift 19 package の相互依存 0、2026 の 201 repo で 13 辺）。
